日常のアウトプットや技術メモを快適に書き残すため、コンテンツファーストな設計思想で知られる note.com のデザインシステムを参考にして個人Webサイトを構築しました。

なぜnoteのデザインアプローチなのか？

Webサイトにおいて、文章そのものの可読性を妨げないミニマルな佇まいは非常に重要です。プライマリカラーを「黒（#000000）」とし、余計な装飾を削ぎ落とすことで、読み手が文章だけに没頭できる体験が生まれます。

「よいデザインとは、できるだけ少ないデザインである。」
— ディーター・ラムス

今回の実装では、以下のトークン設計とコンポーネント構成を重視しました。

  • コンテキストに応じた余白設計： 4px（0.25rem）を基準単位とした一貫したスペーシング。
  • 48dpタッチターゲット： モバイル端末でのタップミスを防ぐため、最小ターゲットサイズをMaterial Design基準に統一。
  • シームレスなダークモード： prefers-color-scheme とクラスによるトグル切替の両立。

デザインシステムのCSS変数コード

カラーパレットやタイポグラフィはCSSカスタムプロパティ（Variables）で一元管理しています。これにより、将来的なテーマ追加やトーンの調整も容易になります。 

:root {
  --color-primary: #000000;
  --color-bg-base: #ffffff;
  --color-text-primary: #1a1a1a;
  --content-max-width: 680px;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-primary: #ffffff;
    --color-bg-base: #111111;
    --color-text-primary: #f0f0f0;
  }
}
